# Khatib Jumat FZ

Aplikasi digital untuk mengelola jadwal khatib Jumat tahun 2027.

## Fitur
- Menampilkan jadwal khatib Jumat berdasarkan bulan dan tanggal.
- Menampilkan informasi masjid, alamat, nama pengurus, dan nomor HP.
- Pengelolaan jadwal melalui halaman Admin.
- Penyimpanan data menggunakan Firebase Firestore.
- Hosting aplikasi menggunakan Firebase Hosting.
- Mendukung instalasi sebagai Progressive Web App (PWA).

## Teknologi
- HTML
- CSS
- JavaScript
- Firebase Authentication
- Firebase Firestore
- Firebase Hosting
